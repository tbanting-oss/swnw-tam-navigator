# SWNW TAM Navigator

Static hosting for the SWNW TAM Navigator dashboard, embedded on
sowhatnowwhat.co.uk via a Wix "Website address" iframe.

The page fetches live data client-side from the Global_Business_TAM_Baseline
Google Sheet (public gviz CSV export) — this repo just needs to serve the
static HTML/JS shell; no proprietary methodology or credentials live here.

Live URL: https://tbanting-oss.github.io/swnw-tam-navigator/
